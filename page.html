DarkStar Tools

DarkStar Tools

DarkStar Tools is a modular security assessment toolkit built with a shared plugin architecture across a terminal-first CLI and PySide6 desktop GUI. It integrates 50+ security modules for reconnaissance, vulnerability assessment, OSINT, exploitation, and post-exploitation, with cross-platform support for Windows, Kali Linux, and Termux. The architecture emphasizes extensibility, automation, structured reporting, and maintainability, allowing new modules to be added without modifying the core engine. Designed for authorized security testing, red-team engagements, and controlled lab environments.

!

AUTHORIZED USE ONLY

DarkStar is built for systems you own, isolated lab environments, or engagements with documented written authorization. It is not designed or distributed for use against systems without consent.
